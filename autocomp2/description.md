Tokens are strings.

Let $f(x)$ be the next token generated by the LLM after input string $x$, as the greedy/argmax choice.
Let $y(x)$ be the activations (at a set of $L$ specified layers) of the LLM at the last token after reading input string $x$.

For any string $x$, consisting of $k$ tokens $x = (t_0, t_1, ..., t_{k-1})$, we write $x_i=(t_0,t_1,...,t_{i-1})$. Thus, $x_i$ has length $i$. And $x_{k} = x$. For notational convenience $x_0$ is the empty string.

$N$ is called the number of conversations.

We use $P^{(k)}$ to indicate the formatted prompt/input text, e.g., for LLM's of type Llama $P^{(k)}=$"<|begin_of_text|><|start_header_id|>system<|end_header_id|>\n\n $S^{(k)}$ <|eot_id|><|start_header_id|>user<|end_header_id|>\n\n $U^{(k)}$ <|eot_id|><|start_header_id|>assistant<|end_header_id|>\n\n". $AC^{(k)}_i = (f(P^{(k)} + R^{(k)}_i), f(P^{(k)} + R^{(k)}_i + f(P^{(k)} + R^{(k)}_i)), ...)$. 
I.e., they are, given the system and user prompt and part (upto, not including, token $i$) of the reference answer, the autocompletion of the LLM.
The length of all $AC^{(k)}_i$ is fixed to be $m$ (called autocompletion length). If the model generates an EOS token before reaching $m$ tokens, generation stops and the remaining positions are left empty (zero-padded in the activation tensor, empty strings in the JSON). We write $AC^{(k)}_i = (ac^{(k)}_{i,0},ac^{(k)}_{i,1},...,ac^{(k)}_{i,m-1})$.
